## 2. 本轮需求审阅发现并处理的边界

| 容易遗漏的问题 | 本稿处理 |
| --- | --- |
| HTTP 能访问 HTTPS 就被当作支持 https:// 代理 | 区分目标站 TLS 和代理入口 TLS，后者要求证书 |
| 三种协议各有一份余额，被同一客户重复消费 | 同一逻辑代理共用权威额度，入口可分开统计 |
| 只统计不扣量，或只禁止新连接 | 字节授权、持久消费、耗尽撤销与存量断连均属于 P0 |
| 并发连接或重启重复使用尚未结算的流量 | 唯一保留、批次幂等、崩溃待核对；不确定额度不自动返还 |
| 充值把人工封禁或换 IP 中的代理重新启用 | 归属、管理意图、任务、健康和额度分别判断 |
| 换上游却仍展示旧 IP，或旧隧道继续走旧出口 | 比较实测 IP、记录配置版本、提交后关闭旧连接 |
| 换 IP 导致客户必须重新配置或余额清零 | 客户入口和身份保持，账务连续 |
| 反复点击确认收款或未来回调重放重复加额度 | 支付确认与入账需唯一业务键、事务/恢复及对账 |
| 创建失败留下监听、端口或赠送额度 | 创建幂等、失败回收/待清理、赠送独立记账 |
| 供应商出故障静默回落服务器公网 IP | 明确失败，禁止自动直连或更换未授权出口 |
| 内部检测混入客户账单，或免计费路径被滥用 | 独立受控探测归集，不接受客户设置的免计费标志 |
| 数据恢复重放旧余额 | 恢复先核对备份后已授权消费，不直接按旧快照放行 |
| fork 了 CLI 就以为改到了协议和流量转发实现 | 登记 core/x 基线，详细设计先验证接缝再决定是否额外 fork |

这是一轮文档自查，不是独立安全审计，也不是计费实现正确性的证明。

## 3. 可证伪的验收场景

所有场景当前状态均为 `not_run`。这里的场景定义不构成 E2E 运行授权。

| 编号 | 场景与关键断言 | 关联需求 |
| --- | --- | --- |
| A-01 | 输入一条有效 ISP，生成唯一 proxy_id、独立客户凭据和三种链接；重复提交不多建资源 | R-03、R-04 |
| A-02 | 分别以 HTTP 普通转发、HTTP CONNECT、HTTPS 代理 TLS、SOCKS5 访问目标；出口均为绑定 ISP | R-01、R-02 |
| A-03 | 用两用户、每人两条代理制造不同流量；四条消费按确定整数值分别一致，互不串账 | R-04、R-06、R-07 |
| A-04 | 同一代理同时使用三种入口；合并消耗等于三者实际消费之和，没有三份可重复余额 | R-02、R-07、R-08 |
| A-05 | 给极小额度，建立双向大流量长连接；授权/消费不超过额度，新连接失败，存量停止，其他代理正常 | R-08 |
| A-06 | 同一代理多进程并发争用最后额度；已确认消费加全部有效/未决保留不超净入账额度，未授权字节不能成功穿过计量边界 | R-08 |
| A-07 | 耗尽时已有空闲隧道被主动关闭，不能在之后恢复传输；断连时延满足详细设计冻结值 | R-08 |
| A-08 | 同一支付订单并发确认、超时重试和重复回调只增加一次指定字节数；未支付订单不增加额度 | R-09 |
| A-09 | 耗尽后续购恢复；人工暂停、用户封禁、节点异常时充值仍不放行 | R-09、R-10 |
| A-10 | 进程/节点重启及消费上报重放后累计量、余额和订单一致；未决保留被隔离，不能当免费余额重用 | R-07～R-09、R-14 |
| A-11 | 更换有效 ISP 后观察到不同出口；客户地址、凭据、身份、额度和历史保留，旧连接关闭 | R-05、R-11 |
| A-12 | 候选上游认证失败、不可达、国家不符或 IP 未变时，不报告换 IP 成功；无效候选不替换原绑定 | R-01、R-05、R-11 |
| A-13 | 换 IP 与耗尽、充值、暂停并发；最终没有越权启用，没有重复授权和遗留旧隧道 | R-08～R-11 |
| A-14 | 上游故障时客户明确失败，目标侧不会观察到中转服务器直连或其他 ISP 出口 | R-01 |
| A-15 | 健康检测有独立流量记录、不扣客户额度；客户无法伪造内部检测身份绕过扣量 | R-05、R-08、R-13 |
| A-16 | 客户 A 猜测 B 的代理/连接/订单/导出 ID，服务端均拒绝，响应无 B 的数据和凭据 | R-04、R-13 |
| A-17 | 创建遇到端口冲突、证书错误或部分下发失败时可恢复/清理，不显示已就绪且不影响已有代理 | R-02、R-03、R-14 |
| A-18 | 认证失败和未转发数据不扣量；转发后失败只记录实际已传输量；诊断不泄露密码和正文 | R-07、R-13 |
| A-19 | 暂停、封禁和凭据重置停止旧授权连接；删除端口复用后旧凭据不能访问新客户服务 | R-04、R-10、R-13 |
| A-20 | 账务服务故障、节点断联或磁盘写入失败时，不继续无限授权；控制台显示异常/待核对 | R-08、R-14 |
| A-21 | 退款/赠送/调整保留操作记录；不能篡改已支付订单直接改余额或返还已经消费的流量 | R-09、R-10 |
| A-22 | 从备份恢复时，先隔离可能重复授权的额度，完成差异核对后才恢复转发 | R-08、R-14 |

## 4. 产品选择核对

主人于 2026-11-07 已确认：

1. 首期人工核实收款并为指定代理入账，在线支付后续接入。对应 D-01。
2. 首期人工替换 ISP 上游换 IP，保持客户连接和余额。对应 D-02。

仍按建议保留、尚未确认为最终规则：上下行合计、十进制 GB、余额归属指定代理、流量不过期，对应 D-03。套餐售价/币种、首个供应商、部署节点、域名和目标容量在详细设计及上线前分别确定；本轮不虚构这些值。
